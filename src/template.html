データの制約（重要・クリックで展開）
  • X / LinkedIn は直接取得できません。検索結果とミラーサイトで本文を確認し、日付は投稿ID（Snowflake）から機械的に復元しています。ページ上の表示日を読んだものではないため、ずれの可能性があります。
  • 初期収集ではYouTubeが繰り返しアクセス制限（429）に遭い、動画の公開日をほぼ取得できませんでした。そのため初期収集分の動画・講演の多くが「不明」です（自動更新で入った動画には YouTube Data API の公開日が付きます）。
  • 「直近1ヶ月」「直近1週間」は、閲覧時点から過去30日 / 7日以内に日付が確認できた項目を対象にします。日付が「不明」の項目（X投稿の一部と初期収集のYouTube動画）は、実際には新しくてもこの絞り込みには出てきません。
  • YouTube対談セクションの初期収集分はoEmbed APIで実在を検証しています（公開日は同APIが返さないため「不明」）。自動更新分はYouTube Data APIの検索結果で公開日付きです。いずれも上の2セクションと重複する動画は除いています。
  • 見出しの多くは英語原文の要約・和訳です。原文は必ずリンク先で確認してください。
  • 「本人の発信」は本人名義の一次ソースのみ。企業ブログはチーム名義だと0件になります（Qwen・Moonshot・Sakana AI・Mistral など）。一方「インタビュー・動画」は本人が話している二次媒体を含みます。
  • この収集で判明した動き: John Jumper が Google DeepMind → Anthropic、Sara Hooker が Cohere を離れ Adaption Labs 創業、Lilian Weng が OpenAI へ復帰との報道、Jerry Tworek が OpenAI 退職と報道。
  • 自動更新の範囲: 初期データは Claude(30体のサブエージェントによるWeb検索・ページ取得)の2026-08-20収集。以後「本人の発信」のうちブログ / Substack / note / 研究所ブログは RSS・Atom フィードから6時間ごとに、「YouTube対談」は YouTube Data API の検索から毎日(50名ずつ交替)自動更新され、20分超の長尺動画でタイトルに氏名を含む直近180日のものだけを採用し、枠が余る場合は収集済みの対談を残します。自動収集された新着は原文タイトルのまま載り、YouTube 動画には公開日が入ります。X・インタビュー・紹介文(事績・所属)は毎月1日にクラウドエージェントが再収集し、複数の報道で確認できた事実だけを反映します。LinkedIn のみ安定した取得経路がなく初回収集(2026-08-20)のままです。紹介文は公開情報に基づく要約で、分類と選定は暫定・所属は変動します。
